Primary Finding

The visual direction is strong, but the implementation is fragmented. Reverb, Granular, and Dynamics should become the canonical advanced-page pattern. Global, Synth, Drums, Earth, Delay, and Routing should be migrated into shared page, card, toolbar, toggle, chip, and matrix primitives.

Recommended Primitive Stack

TokensOne imported source for colors, spacing, type, radii, borders, and page accents.
Page ShellConsistent header, preset placement, columns, max width, and responsive behavior.
CardsSectionCard for ordinary controls; EngineCard for sources and voices with left accent rails.

Page Change Map

Global

Add PageHeader, convert mixer/preset/harmony/utility cards to SectionCard, and normalize local type tokens.

Synth

Replace custom source bar and synth cards with PresetToolbar plus EngineCard. Reduce micro font-size drift.

Drums

Share source/pattern/master toolbar primitives with Synth, and make voice cards a reusable EngineCard variant.

Earth

Move instructions to help, reuse MatrixSurface with Routing, and standardize source chips.

Granular

Keep as near-canonical. Extract global bar, chips, toggles, and section cards into shared primitives.

Delay

Use SectionCard for ordinary modules and reserve left-accent EngineCard for Echo Line and Clocked Space.

Reverb

Use this page as the extraction source for PageHeader, PresetToolbar, SectionCard, and SectionHead.

Dynamics

Add missing tokens and unify OFF/FX Off labels through one toggle state component.

Routing

Wrap the matrix in PageHeader plus SectionCard, move long guidance to help, and share MatrixSurface with Earth.

Snowflake/simple

Keep the immersive mode, but move inline styles to tokens and align buttons with the shared icon-button system.
