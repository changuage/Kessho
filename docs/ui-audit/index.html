Primary Finding

The visual direction is strong, but the implementation is fragmented. Reverb, Granular, and Dynamics should become the canonical advanced-page pattern. Global, Synth, Drums, Earth, Delay, and Routing should be migrated into shared page, card, toolbar, toggle, chip, and matrix primitives.

Pre-Implementation Decision Checks

Before building the unified UI, approve the scope and exception rules. The big decision is where to borrow Journey's aesthetic language without importing Journey's page-specific behavior.
1. SnapshotCapture every page in default, active, edited, disabled, and mobile states.
2. ComparePlace Reverb, Granular, Journey, Synth, Drums, Routing, and Dynamics side by side.
3. DecideApprove shared primitives, page exceptions, color meaning, and density rules.
4. PilotImplement one ordinary page and one dense/matrix page before migrating everything.
ConfirmedAesthetic vs LogicJourney contributes colors, glass, dots, and glow only. Each page keeps its own ON/OFF, freeze, mute, solo, and engine behavior.
ConfirmedPage Personality BoundariesSource/page accents are allowed in headers, selected chips, source rails, visual traces, matrix row identity, and not every control.
Needs inputDot + Glow RulesClickable dots are allowed only where the page already has a toggle. Read-only dots report activity, focus, progress, or active process.
PrototypeTwo-Page PilotTest the system on one advanced page like Reverb or Granular and one dense page like Drums, Routing, or Synth. Do not migrate all pages until both feel right.
Confirmed directionPage -> Sound Engine ColorsPreset hierarchy can explain structure, but colors should follow page identity and sound-engine identity, including routing and matrix representations.
PrototypeSlider + Matrix BehaviorCheck drag, keyboard, reset, disabled, walking/randomized, range/dual, ghost preview, and value-readout behavior before replacing native ranges.
Implementation defaultTypography + DensityUse one compact type scale, spacing scale, radius scale, and icon/button grammar. Dense views can compress spacing, not invent a separate style system.
Implementation defaultAccessibility PassCheck contrast on low-alpha fills, visible keyboard focus, hit targets, reduced motion, color-blind readability, and mobile collapse for every primitive.
Migration guardRegression BaselineSave before/after screenshots and token counts. Watch for broken layout, over-bright accents, lost source identity, unreadable disabled states, and visualizer drift.

Final Checks Before Implementation

All pre-implementation decisions are now confirmed. The remaining work is implementation QA: snapshots, token inventory, behavior parity, accessibility, regression review, and type/test checks.
Pilot OrderConfirmed: implement in two waves. Reverb + Drums first, then Granular + Routing.
State PriorityConfirmed: disabled/off wins first, then danger/record, warning, selected/focus, and finally engine active color.
Engine Palette FreezeConfirmed: freeze the Journey-softened engine palette for the pilot, then adjust only after side-by-side screenshots prove a mismatch.
Help MemoryConfirmed: dismissed help is remembered per page or complex panel, with Show Help / Help / ? always available to reopen it.
Visualizer EligibilityConfirmed: use 5B only where visual data can be edited or inspected. Never add fake handles.
Migration ToleranceConfirmed: migrate incrementally. Shared tokens and primitives land first, then pilot pages, then the remaining pages after screenshot review.
Confirmed state priority: when one element has more than one meaning, the strongest meaning controls the visual treatment. Recommended order: disabled/off, danger/record, warning, selected/focus, then engine active color.
Disabled / Off WinsIf Kick is normally orange but the voice is off or unavailable, the dot becomes grey with no glow. Engine color does not show.
Danger / Record WinsIf a control is recording or destructive, the record/danger treatment beats selected or engine color so the risky state is never hidden.
Warning Wins NextIf a value needs attention, warning styling beats normal focus or active color until the issue is resolved.
Selected / Focus NextIf the control is being edited or inspected, focus/selection styling appears unless disabled, danger, or warning is present.
Engine Color LastEngine color is the normal musical identity: Pad blue, Kick rust, Reverb violet. It appears only when no stronger state needs attention.
Why It MattersThis prevents active colors from hiding important states, while still letting each engine keep its identity in normal use.
