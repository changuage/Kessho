# Kessho Product Reference Isolation

Old TypeScript audio code remains available for `web-ts` reference mode, parity comparison, migration conversion, and tests. It must not become the production musical brain for `core-product`.

## Allowed Core Product Imports

- Generated Product schema/event/param files.
- Product-specific host/runtime/event/snapshot/asset/telemetry modules.
- `CoreProductAssetAdapter` for host-owned fetch/decode/register I/O only.
- `CoreProductHostDebugTelemetry` for adapting Product Core telemetry into existing UI debug snapshot shapes only.
- `CoreProductHostRuntimeGuards` for strict host-side validation and UI audition state normalization only.
- `CoreProductHostSequencerEvolve` for telemetry-bar driven Product sequencer evolve event timing only.
- `CoreProductHostSequencerEvolveConfig` for preserving Product sequencer evolve method/sub-lane config before event dispatch only.
- `CoreProductHostSequencerSubLaneEvolve` for host-side Product sub-lane length/direction drift until Product Core owns the scheduler.
- `CoreProductHostSequencerRangePayload` for translating Product range-mode sub-lane values into UI reset/evolve payloads only.
- `CoreProductHostSynthNoteRangeEvolve` for host-side Product note-range evolve forwarding until Product Core owns note-range pitch scheduling.
- `CoreProductHostHarmonyState` for projecting Product harmony telemetry into existing UI harmony state shapes until Product Core exposes that state directly.
- `CoreProductHostSequencerSwing` for Product-safe sequencer swing normalization and host-side swing drift only.
- `CoreProductHostSequencerUiState` for reconciling Product Core sequencer UI state telemetry into host replay caches and UI payloads only.
- `CoreProductHostSequencerClock` for Product-safe sequencer clock-division normalization only.
- `CoreProductHostSequencerHome` for host-side Product sequencer home-state reconciliation only.
- `CoreProductHostSynthPitch` for Product-safe synth/drum sequencer pitch conversion only.
- `CoreProductHostSequencerVisuals` for deriving UI playhead positions from Product telemetry and Product-safe Euclidean masks only.
- Type-only app interfaces from `src/audio/engine.ts`.
- Asset manifest helpers such as `pianoSamples` and the versioned `coreProductAssetManifest.json`.
- Unit/default helpers used only for serialization, such as `delayBuses`, `outputTrims`, `transport`, and selected UI state constants.
- `distanceMacro` only as a temporary source-distance snapshot shaping bridge.
- `coreProductSoundscapesSnapshot` only as the Product snapshot helper for soundscape module params and layer route slots.
- Shared serializer shaping helpers such as `granularMacroCore`, when they do not import old Web engine runtime modules.
- `waterPresets` only as a temporary Water/Soundscape preset morph bridge for Product snapshot serialization.
- Generated preset ID, mode ID, Pad/Lead/Drum reconstruction, delay-division, and primitive snapshot-state helpers live outside old catch-all compatibility bridges.
- `padPresets` only inside `CoreProductPadPatch.ts` as a labeled `PRODUCT_CORE_PAD_OVERRIDE_BRIDGE` conversion bridge for bounded sparse Pad overrides and remaining non-reconstructable exact Pad fallback.
- `lead4opfm` only inside `CoreProductLeadPatch.ts` as a labeled `PRODUCT_CORE_LEAD_OVERRIDE_BRIDGE` conversion bridge for bounded sparse Lead overrides and remaining non-reconstructable exact Lead fallback.
- Drum custom controls serialize through generated voice preset IDs, morphs, source level/reverb, and bounded sparse Drum overrides in `CoreProductDrumPatch.ts`; exact Drum arrays remain only for legacy compatibility surfaces.

## Forbidden Production Imports

`core-product` production modules must not import old TypeScript musical-brain modules such as `engine`, `coreEngineHost`, `drumSynth`, `synthSeqEvolve`, `drumSeqEvolve`, `granularSeqEvolve`, `seqEvolveCore`, `drumSequencer`, preset randomizers, or legacy sonic parity harnesses as runtime dependencies. Current exceptions must be tabled above, including the documented `coreProductArrangementScheduler` bridge to `harmony`, `rng`, and `scales`, plus snapshot-only compatibility helpers such as `waterPresets`.

Classification vocabulary:

- `CANONICAL_GENERATED_SCHEMA_HELPER`: generated Product schema/ABI helper or thin Product host adapter.
- `TEMP_COMPAT_WEB_REFERENCE`: temporary web compatibility bridge with a Product Core replacement owner and removal phase.
- `TEST_ONLY_REFERENCE`: reference import allowed only in tests/parity harnesses, never Product host runtime.
- `DEPRECATED_BRIDGE_FIELD`: snapshot/ABI bridge field retained only until C++ can reconstruct state from generated IDs plus user overrides.
- `FORBIDDEN_FOR_CORE_PRODUCT`: old musical-brain runtime dependency that must fail static audit.

## Retirement Rule

Temporary reference imports must have a documented bridge policy and a static audit. When equivalent generated Product Core IDs plus user overrides can reconstruct the state in C++, the reference import must be removed.
