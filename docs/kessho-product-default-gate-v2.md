# Kessho Product Default Gate v2

Product Default Gate v2 is retired. The maintained gate is Product Default Gate v3.

- Current gate doc: `docs/kessho-product-default-gate-v3.md`
- Current command: `npm run core:product:default-gate-v3`
- Compatibility alias: `npm run core:product:default-gate-v2` runs the v3 guard

`core-product` remains selectable but must not become the web default while Product Default Gate v3 is blocked.
