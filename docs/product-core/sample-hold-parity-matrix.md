# Product-Core Sample-And-Hold Parity Matrix

Product-core sample-and-hold ranges are routed through `ProductEnginePort`/`ProductEngineProxy` into `SetModulationRange` ProductEvents. Normal live controls use ProductEvents; full snapshot reloads are not part of trigger behavior.

| Case | web-ts expected behavior | product-core path | UI feedback | Test | Status | Notes |
|---|---|---|---|---|---|---|
| Case 01 timed global | Global Product params sample at the timed sample-and-hold cadence, keep min/max, and apply only while render time advances. | `targetId=0`, Product param id, timed bus. | Generic sample-hold telemetry publishes trigger positions/flash for mounted dual sliders. | `ProductSampleHoldParityTests::requireTimedGlobalParam`; browser `sample-hold-ui`. | pass | Covers MasterGain, 10 Hz interval, trigger source `0`, no unsupported/fallback diagnostics. |
| Case 02 source morph | Source morph ranges sample per source trigger with deterministic seed and preserved range. | Source target + `SourceMorph`; range state records current/counter/source after trigger. | Source morph callback publishes pad/lead trigger positions where those sliders are mounted. | `ProductSampleHoldParityTests::requireSourceTriggerRanges`. | pass | Returned audio value is unchanged from the existing sampler; telemetry now mirrors the sampled value. |
| Case 03 source distance/expression | Source distance and expression ranges sample per source trigger with deterministic seed and preserved range. | Source target + `SourceDistance`/`SourceExpression`; range state records current/counter/source after trigger. | Distance callbacks publish slider indicators; expression is exposed through source expression callback/visualizer telemetry rather than a dedicated expression dual slider. | `ProductSampleHoldParityTests::requireSourceTriggerRanges`. | intentionally different | Expression has no direct web-style dual-slider surface in the current Product UI; trigger state is visible in telemetry and visualizer callback. |
| Case 04 drum morph | Drum morph ranges sample per drum trigger for the selected voice. | `KESSHO_PRODUCT_DRUM_RANGE_TARGET_BASE + voice`, `SourceMorph`. | Drum morph callback publishes the voice position on the drums page. | `ProductSampleHoldParityTests::requireDrumTriggerRanges`. | pass | Voice-index callback matches existing Product drum callback contract. |
