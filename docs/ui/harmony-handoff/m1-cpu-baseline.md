## How to compare

- Rerun `npm run core:product:cpu` (about 40 s) on the same machine and compare the two scenario rows in section 2: avg CPU % (budget 25 for disabledFx, 35 for activeFx), p95 ms (budget 1.333 and 2.000), p99 ms (budget 2.667 for both) and simulated underruns (must stay 0). Peak CPU % is noisy; compare its order of magnitude, not its exact value. Avg CPU % of 5 to 6 in the disabled scenarios and about 8 in the active FX scenario are the reference points.
- Only compare runs on the same machine and at similar load. The baseline is a single run and the script retries once on jitter.
- Once the five stale evidence reports are regenerated (their generators are listed in section 1), rerun `npm run core:product:cpu-scenarios` and `npm run core:product:module-cpu` to get pass/fail for those checks at a milestone.
